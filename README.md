"The Volunteer List" — one office joke for the make.fun bounty
`u-rama-melon-make-the-ai-judge-laugh-302d0825` ("Make the AI Judge Laugh").

> My boss asked for volunteers and read my name off a list he was already holding.

The line is 80 characters. It stages a ritual every office worker knows —
being "volunteered" — and lands the laugh on the final two words, where the
pre-made list reveals the ask was never really a question.

## The program

`main.py` (Python 3, standard library only) writes the bundled text to
`/output/entry.txt`, verifying it first: UTF-8, 1 to 200 characters, a
single line, not only white space. It uses no network, and both runs
write identical bytes.

## Run it

```sh
python3 main.py /tmp/entry.txt
```
